# Contributing

We welcome bug reports, documentation improvements, new read-only tools, and security reviews.

1. Check the roadmap and open issues.
2. Propose NMM API endpoints with **documented** request/response behavior and minimum permissions.
3. Add tests covering successful responses, failures, pagination, missing permissions and cross-account access denial.
4. Never submit tokens, secrets, real customer data, private endpoint URLs, production logs or proprietary Nerdio documentation.
5. Keep actions read-only unless an approved security design and human-approval mechanism are implemented.

Any code copied from other repositories must retain attribution, applicable license and NOTICE requirements.
